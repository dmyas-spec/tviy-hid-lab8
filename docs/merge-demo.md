# Навчальне злиття гілок

Порядок релізу: виконати збірку, перевірити Git-статус, а також сайт на телефоні та комп’ютері.

У лабораторній навмисно змінено один рядок у main та feature/release-checklist. Під час merge виник конфлікт; фінальний текст об’єднує обидві перевірки. Маркери конфлікту прибрано, файл додано до індексу та злиття завершено комітом.
