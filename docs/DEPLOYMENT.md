# Публікація лабораторної №8

GitHub Pages використовує main та кореневу папку /. У ній є index.html, локальні CSS, JS, assets і .nojekyll. Посилання відносні, тому сайт може працювати за адресою /назва-репозиторію/.

Netlify використовує npm run build:site та папку dist. Команда спочатку генерує Tailwind, а потім копіює лише публічні файли. Папки .git, node_modules, звіти й докази не потрапляють у dist.

## Локально

1. Відкрити lab-08-git-deploy.code-workspace у VS Code.
2. Для перегляду index.html використати Live Server, порт 5508.
3. Для зміни стилів встановити залежності npm ci та виконати npm run build:site.

## Робочий цикл Git

git status → зміни у файлах → git diff → git add → git commit → git push.

Після появи змін у віддаленому репозиторії: git pull --ff-only.

Гілка із завершеною зміною зливається в main. Для навчальної демонстрації конфлікту використовується окремий документ; службові маркери конфлікту не повинні залишатися у фінальних файлах.
