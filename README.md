# Твій хід - лабораторна №8

Навчальний лендинг настільних ігор «Твій хід», бізнес-тематика «Кубики та картки».
Основа - власний проєкт №7. Лабораторна №8 присвячена Git, GitHub та деплою; дизайн і контент лендингу збережені.

## Технології та можливості

HTML, Tailwind CSS 3.4.17, JavaScript; пошук, навчальний кошик, квіз, FAQ, YouTube, Google Maps і Windy.
Кошик і відповіді квізу зберігаються тільки в пам'яті сторінки. Платежів та реального надсилання форми немає.

## Запуск

Відкрити lab-08-git-deploy.code-workspace у VS Code, далі index.html через Live Server (порт 5508).
Готовий CSS включено. Для редагування та збірки: npm ci, потім npm run build:site.

## Структура

index.html - лендинг; confirmation.html - підтвердження форми; js/store.js - пошук і кошик; js/landing.js - квіз.
tailwind.config.cjs - палітра й компонування дизайн-системи; css/tailwind.css - готовий CSS.
scripts/build.mjs готує тільки публічні файли для dist; netlify.toml задає автоматичну збірку.

## Контроль версій

Основна гілка: main. Завершені зміни з feature-гілок зливаються через merge.
Коміти мають змістовні назви з префіксами feat, build, docs і fix.
.gitignore виключає залежності, dist, .env, журнали, PDF та ZIP.
Робочі команди й пояснення: [деплой](docs/DEPLOYMENT.md) та [навчальне злиття](docs/merge-demo.md).

## Публікація

GitHub Pages: гілка main, коренева папка /. Netlify: npm run build:site, папка dist.
Перевірені адреси додаються після фактичної публікації.
